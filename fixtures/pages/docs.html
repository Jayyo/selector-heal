Getting started

Install the package and create a client.

pip install acme-sdk
from acme import Client
client = Client(token="...")

Your first request

client.items.list(limit=10)

See Pagination for large result sets and Error handling for retries.

Using a proxy

Set HTTPS_PROXY before creating the client.
